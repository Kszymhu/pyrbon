# pyrbon

Pyrbon is a command-line tool for creating structures of carbon allotropes.

## Installation

Currently, you have to clone the repo and install it using pip.

```bash
pip install git+ssh://git@github.com/Kszymhu/pyrbon.git
```

## Usage

```bash
Pyrbon [generator] [generator-specific arguments]
```

### Generators
- diamond - generate a diamond
- fullerene - generate a fullerene
- graphene - generate a graphene sheet
- graphite - generate layers of graphite
- mwcnt - generate a russian-doll model multi-walled carbon nanotube
- pah - generate a policyclic aromatic hydrocarbon (not an allotrope but who cares)
- parchment - generate a parchment model multi-walled carbon nanotube
- swcnt - generate a single-walled carbon nanotube

### Diamond generator
#### Usage
```bash
Pyrbon diamond [arguments]
```

#### Arguments
- -a, --dummy_a INTEGER: dummy argument A
- -b, --dummy_b FLOAT: dummy argument B

#### Examples
Dummy example
```bash
Pyrbon diamond -a 21 -b 3.7
```
